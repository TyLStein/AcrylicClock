# Project Name

> Acrylic Nightstand Clock

## Project Owner

**Name:** Tyler Stein
**Virginia Tech Email:** tyler858@vt.edu

## Project Overview

I am building a clock than can go on your nightstand or wherever you want. It will tell you the date, time and temperature. Its outside is acrylic and has RGB LEDs around the front, with a 3D printed inside to keep the circuit part and let it slide out to change anything. It uses an ESP32, e-paper display, RTC, thermistor, LED strip, and a LiPo battery. While its practical use is good, I am also doing this project to learn more as an EE major as it has many skills that I am interested in. 

## What I Hope to Learn

There are many skills that I want to learn with this. One is soldering, which I have never done before. I plan on doing AmpLab's soldering courses for that. The next is creating a PCB, as I haven't done that either. While I have used a laser cutter before, I want to get more used to it and see how different acrylic works together, as I am planning on having two layers of acrylic, one clear one frosted, on my front to see how it changes how the colors are displayed. Next is circuit building and piecing everything together, as well as coding everything. Lastly, I want to learn more fusion work and 3D printing.
