# Acrylic Nightstand Clock

## Project Owner

**Name:** Tyler Stein

**Virginia Tech Email:** tyler858@vt.edu

## Project Overview

I am building a clock than can go on your nightstand or wherever you want. It will tell you the date, time and temperature. Its outside is acrylic and has RGB LEDs around the front, with a 3D print design for the inside. The system is powered by a LiPo battery and includes a charging module, an ESP32, RTC, and e-paper display.

## What I Hope to Learn

There are many skills that I want to learn with this. One is soldering, which I have never done before. I plan on doing AmpLab's soldering courses for that. The next is creating a PCB, as I haven't done that before. I also want to get more comfortable with 3D design and acrylic fabrication.
